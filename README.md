# Dashboard de Análise de E-commerce

## Sobre o projeto

Este projeto apresenta um dashboard interativo desenvolvido com Python, Pandas, Plotly e Dash para visualizar e analisar dados de produtos de e-commerce.

## Gráficos disponíveis

- Histograma da distribuição dos preços.
- Dispersão entre preço e número de avaliações.
- Mapa de calor das correlações.
- Gráfico de barras por gênero.
- Gráfico de pizza por material.
- Distribuição da densidade dos preços.
- Regressão linear entre preço e nota.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Dash

## Como executar

1. Instale as dependências com `pip install -r requirements.txt`.
2. Coloque o arquivo `ecommerce_estatistica.csv` na mesma pasta de `app.py`.
3. Execute `python app.py`.
4. Abra `http://127.0.0.1:8050/` no navegador.

## Objetivo

Facilitar a exploração dos dados, a visualização de padrões e a interpretação das relações entre as características dos produtos.
